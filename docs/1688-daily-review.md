# 1688 每日询盘复盘流程

## 目标

每天把前一天的客服询盘整理成可复盘的输入，识别高意向客户、客户反复关注的产品问题、销售沟通卡点和需要跟进的事项。

## 推荐流程

1. 使用 [1688-chat-downloader](https://github.com/794249481-droid/1688-chat-downloader) 按日期导出前一天的记录。
2. 或使用 [lai-assistant](https://github.com/794249481-droid/lai-assistant) 按客服和客户旺旺号精确检索。
3. 复制到个人工作目录后，删除客户姓名、旺旺号、手机号、邮箱、订单号、地址和图片。
4. 用脱敏后的 JSON 运行：

```sh
python3 main.py path/to/sanitized-export.json --mode json --output-dir reports
```

5. 检查 HTML、CSV 和 JSON 报告，确认客户分级和需求摘要与原始对话一致。
6. 把确认后的重点需求带入销售知识库或销售脑，生成下一步跟进动作。

## 建议的复盘问题

- 哪些客户明确表达了数量、预算或交期？
- 哪些客户反复询问同一个功能、规格、材质、包装或认证？
- 哪些客户已经进入比价、决策或售后阶段？
- 哪些询盘没有得到明确的下一步？
- 最近一周是否出现新的行业词、应用场景或市场需求？

## 隐私边界

原始聊天记录只保存在受控的本地目录，不要上传 GitHub，也不要把未脱敏内容粘贴到公共 AI 工具。分析结果也可能包含商业信息，分享前需要再次检查。分析器的结果是辅助判断，发送客户消息或做产品决策前必须人工确认。
